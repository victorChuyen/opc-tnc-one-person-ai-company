# ✅ Audit Checklist 20 Điểm

## 🔴 Ưu Tiên Cao (Fix Ngay)
- [ ] Pixel/CAPI tracking chính xác
- [ ] Conversion window phù hợp business cycle
- [ ] Campaign objective đúng mục tiêu
- [ ] Budget allocation theo Pareto (80/20)
- [ ] Exclusion audiences (khách hàng hiện tại, nhân viên)

## 🟡 Ưu Tiên Trung Bình
- [ ] Ad copy testing (min 3 variations)
- [ ] Creative format diversity (image, video, carousel)
- [ ] Audience overlap < 30%
- [ ] Frequency cap phù hợp
- [ ] Landing page alignment với ad message
- [ ] UTM tracking parameters

## 🟢 Ưu Tiên Thấp (Optimize)
- [ ] Placement optimization
- [ ] Schedule optimization (dayparting)
- [ ] Bid strategy review
- [ ] Creative fatigue monitoring
- [ ] Lookalike audience quality
- [ ] Retargeting funnel đầy đủ
- [ ] A/B test structure
- [ ] Attribution model review
- [ ] Cost cap vs bid cap testing
- [ ] Account structure (CBO vs ABO)
