# 🧮 Hormozi Value Equation

## Công Thức
$$\text{Value} = \frac{\text{Dream Outcome} \times \text{Perceived Likelihood of Achievement}}{\text{Time Delay} \times \text{Effort \& Sacrifice}}$$

## Cách Tăng Value
1. **Tăng Dream Outcome** → Hứa hẹn kết quả lớn hơn, cụ thể hơn
2. **Tăng Perceived Likelihood** → Social proof, case study, guarantee
3. **Giảm Time Delay** → Cho kết quả nhanh hơn, "trong 7 ngày đầu"
4. **Giảm Effort** → Done-for-you, automation, 1-click setup
