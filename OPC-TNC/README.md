# 🏢 OPC TNC — Bộ Não Doanh Nghiệp 1 Người

> **Vault Obsidian tập trung** cho toàn bộ hoạt động kinh doanh TNC AI.
> Mọi dự án, agent output, daily notes và tài liệu chiến lược đều nằm tại đây.

## Cách sử dụng

1. Mở **Obsidian** → Open Vault → chọn thư mục `D:\OPC-TNC\OPC-TNC`
2. Cài plugins: **Dataview**, **Templater**, **Calendar**
3. Bắt đầu từ `00-INBOX/dashboard.md` để xem tổng quan

## Cấu trúc Vault

| Thư mục | Mục đích |
| :--- | :--- |
| `00-INBOX` | Ghi nhanh, ý tưởng, link tạm |
| `01-PROJECTS` | MOC (Map of Content) cho từng dự án |
| `02-AREAS` | Các mảng trách nhiệm: Marketing, Sales, Creative, Ads, Finance |
| `03-RESOURCES` | Framework, Skills catalog, Agent roster, Tech stack |
| `04-DAILY` | Nhật ký CEO hàng ngày |
| `05-MEETINGS` | Ghi chú cuộc họp, demo call |
| `06-CANVAS` | Sơ đồ trực quan (Obsidian Canvas) |
| `07-TEMPLATES` | Templates cho mọi loại note |
| `08-ARCHIVE` | Dự án đã hoàn thành / tạm dừng |
